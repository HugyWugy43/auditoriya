## Примечания по созданию диаграмм

Для создания визуальных диаграмм рекомендуется использовать:
- **draw.io** (diagrams.net) - для UML, DFD, ER диаграмм
- **PlantUML** - для текстового описания UML
- **pgAdmin** или **DBeaver** - для визуализации ER диаграмм БД

Файлы диаграмм можно сохранить в формате:
- `.drawio` для draw.io
- `.png` или `.svg` для экспорта
- `.puml` для PlantUML
