## Архитектурные паттерны

### Микросервисная архитектура
- Разделение на независимые сервисы
- Слабая связанность
- Высокая связность внутри сервиса

### API Gateway Pattern
- Единая точка входа
- Маршрутизация запросов
- Агрегация данных

### MVC (Model-View-Controller)
- Model - JPA Entity
- View - REST API / GraphQL
- Controller - REST Controllers

### Repository Pattern
- Абстракция доступа к данным
- Инкапсуляция логики работы с БД

## Языки моделирования и нотации

### UML (Unified Modeling Language)
- **Class Diagram** - структура классов
- **Sequence Diagram** - взаимодействие компонентов
- **Component Diagram** - архитектура компонентов
- **Deployment Diagram** - развертывание системы

### DFD (Data Flow Diagram)
- Контекстная диаграмма (уровень 0)
- Детализация процессов (уровень 1, 2)
- Потоки данных между компонентами

### ER (Entity-Relationship)
- Модель данных
- Сущности и их атрибуты
- Связи между сущностями

## GraphQL Schema Language

Используется для определения схемы GraphQL API:
- Типы данных
- Запросы (Queries)
- Мутации (Mutations)
- Подписки (Subscriptions)

Пример:
```graphql
type User {
    id: ID!
    username: String!
    email: String!
}

type Query {
    users: [User!]!
    user(id: ID!): User
}

type Mutation {
    createUser(username: String!, email: String!): User!
}
```
